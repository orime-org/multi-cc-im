Codex native question name flow

Design draft. User-visible routing follows the native /rename session name.

Read loaded Codex root sessions

Existing local App Server connection supplies thread metadata and current names.

↓
Subscribe to uniquely named eligible sessions

Native IDs identify the corresponding protocol subscription.

↓
Receive a native Agent question

Keep its original request, turn, item and question IDs; carry the session name.

↓
Deliver to Feishu with the session name

Existing IM mode and owner/chat gates apply.

↓
Receive the user's correlated answer

Refresh the native name and pending status; validate the original owner and answer.

↓
Respond to the original native request

Native resolution confirms completion. Existing terminal-first and late-answer behavior applies.

Name missing or duplicated during metadata checks

Report the naming problem and /rename guidance. The affected request remains handled by Codex.

A later metadata refresh rechecks the current names and native pending state.
