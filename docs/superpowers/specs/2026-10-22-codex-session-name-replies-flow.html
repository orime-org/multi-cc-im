Codex session reply flow

Design demonstration: each Stop carries a thread id and reply. A local metadata lookup supplies the source name.

  1. Stop: internal thread id + reply text
  2. Reply gates: IM mode + IMOrigin + live daemon
  3. Local UDS: thread/read → native session name
  4. Atomic session reply event → shared watcher
  5. Bridge: IMOrigin + sourceTag = session name → IM
